# Tin whistle samples

One recorded note per file from a real D tin whistle, used for playback in the app.

These recordings are cut from **"Báidín Fheilimí" played on a D tin whistle by Jules Grandgagnage**
([Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Baidin_Feidhlimidh_tinwhistleD.ogg)),
licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Changes made: individual notes cut out, loudness evened out, a crossfaded sustain loop
added to each, and a short fade at the end. These sample files are therefore also
CC BY-SA 4.0 (this licence covers only the files in this folder, not the rest of the app).

`samples.json` lists each file's note (sounding pitch, MIDI number), its tuning offset in cents
and its loop points in seconds. To use different recordings, replace the WAV files and
update `samples.json`.
