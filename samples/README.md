# Test sheet music

Files for trying out the app, roughly easiest to hardest. Upload them on the **+ New tab** page. For the multi-image ones, select all the pages at once, in order.

| File(s) | What it tests | Source / licence |
| --- | --- | --- |
| `ode-to-joy-engraved.pdf`, `.jpg` | Clean, simple melody in C. The app should suggest a whistle-friendly key. No chords printed, so chords are suggested. | Made by this app (abcjs), public domain melody |
| `holly-and-the-ivy.pdf` | Single melody line with lyrics, key of F, pickup bar | [Mutopia](https://www.mutopiaproject.org/) (Geoffrey Lehr), Public Domain |
| `holly-and-the-ivy-phone-photo.jpg` | The same page made to look like a phone photo: tilted, uneven light, soft focus, heavy JPEG | Derived from the above, Public Domain |
| `good-king-wenceslas.pdf` | Four-part hymn (SATB). The melody is the top voice of the upper staff, and it has a printed tempo. | Mutopia (James Kilfiger), Public Domain |
| `greensleeves-voice-guitar.pdf` | Vocal melody with 5 verses of lyrics above a guitar part with tab, 2 pages, ties | Mutopia: "Greensleeves" typeset by David Kastrup, CC BY-SA 4.0 |
| `amazing-grace-bagpipes.pdf` | Grace notes on almost every beat (should be ignored), E♭ with 3/8 time | Mutopia: arr. Breizh Partitions, CC BY-SA 3.0 |
| `scarborough-fair-lead-sheet.pdf` | Lead sheet with printed guitar chords, Dorian mode | *The Public Domain Song Anthology* (D. Berger & C. Israels), p. 291, CC0 |
| `shenandoah-lead-sheet.png` | Lead sheet with chords, given as an image | Same anthology, p. 297, CC0 |
| `londonderry-air-lead-sheet.png` | Lead sheet with chords, superscripts (C⁷), a second row of alternative chords, 2 verses, 1st/2nd endings | Same anthology, p. 208, CC0 |
| `danny-boy-1913-scan-page1..4.jpg` | Real scan of a 1913 printed piano/vocal edition across 4 images: aged paper, the melody inside a piano score. The same tune as Londonderry Air, for comparison. | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Danny_Boy_p4_-_sheet_music_1.jpg), Public Domain (1913) |
| `schubert-an-die-musik-voice-piano.pdf` | Art song: vocal line above a piano part, 2 pages, wide vocal range | Mutopia, Public Domain |

The CC BY-SA files may be shared and changed as long as they credit the typesetter and keep the same licence.
